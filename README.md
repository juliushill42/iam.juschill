# IAM Identity Mesh

One canonical Julius Cameron Hill identity record mirrored across every `iam.<domain>` endpoint.

## One command

```bash
./bootstrap.sh
```

Machine endpoints: `/identity.json`, `/identity.jsonld`, `/timeline.json`, `/evidence.json`, `/domains.json`, `/llms.txt`, `/llms-full.txt`, `/.well-known/julius-cameron-hill.json`, `/robots.txt`, `/sitemap.xml`.

Edit `config/domains.json` to add domains, rerun `./bootstrap.sh`, redeploy.
